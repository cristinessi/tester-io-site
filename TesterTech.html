Tester Tech · Field guide

Tools we trust. Swapped when something better shows up.

A live catalog of the headless browsers, automation frameworks, load generators, and dashboards behind every Tester.io engagement. Curated, battle-tested, and updated when our minds change.

01 · Browser automation

What runs in the browser.

End-to-end, visual regression, and cross-browser jobs. We default to Playwright on new work and keep Cypress for projects already invested in it.

i

Playwright

Daily driver

Headless & headed Chromium/Firefox/WebKit. Trace viewer is the killer feature — it makes flake autopsies a 30-second job.

ii

Cypress

Legacy + UI suites

Still the friendliest UX for teams new to E2E. We keep it on accounts where the suite predates us.

iii

WebdriverIO

Multi-protocol

When clients need WebDriver protocol parity across desktop + mobile in one runner.

iv

Selenium 4

Enterprise grid

Still the right answer for distributed grids inside corporate networks. We don't reach for it on greenfield.

02 · Mobile

What runs on a device.

Real-device clouds, simulators, and a small drawer of physical phones in the studio. Maestro for fast smoke flows; Appium when we need the full WebDriver surface.

i

Maestro

Smoke + critical paths

YAML-defined flows that read like a stage direction. Two minutes from zero to a working test.

ii

Appium 2

Full coverage

iOS + Android with one driver. Worth the setup tax when you need parity with desktop suites.

iii

Detox

React Native

Native instrumentation for RN apps. Fast, deterministic — but only as good as your test IDs.

iv

XCUITest / Espresso

Platform-native

When teams want to live entirely in Xcode or Android Studio. We write the harness, the team owns the tests.

03 · API & integration

What runs over the wire.

Contract tests for services we don't own, integration tests for the ones we do, and a Postman collection per partner. Pact for consumer-driven contracts when teams are distributed.

i

Postman

Sandbox + docs

Where new endpoints live before they get codified. Every engagement starts with a shared workspace.

ii

REST Assured

JVM integration

Fluent Java for teams already on Spring. Reads like prose, fails clearly.

iii

Karate

DSL-first

Gherkin-flavored API testing. Lowers the bar for QA engineers to own the test suite.

iv

Pact

Consumer contracts

The right answer when frontend and backend deploy on different cadences. Catches breakage before staging.

04 · Performance & load

What runs under pressure.

Load shapes, soak runs, and Black Friday rehearsals. k6 for almost everything; Artillery when the team is JS-fluent and needs to run from their laptop.

i

k6

Load + smoke

JS-defined load with first-class CI integration. We run k6 Cloud for distributed bursts, OSS k6 for CI.

ii

Artillery

Quick scenarios

YAML + JS hooks. Best for small soak runs from a laptop, or to spike a single endpoint.

iii

Locust

Python shops

When the team writes Python by default. Distributed mode is clean; the UI is honest.

iv

JMeter

Enterprise + protocols

Still the right answer when the protocols are odd (JMS, FTP, JDBC). We don't reach for it on greenfield.

05 · Security & static analysis

What runs on the way in.

Pre-merge code scans, dependency triage, and pen-test fixtures. Not a substitute for a security team — but most clients don't have one, so we run the basics.

i

OWASP ZAP

DAST

Automated baseline scans against staging. Catches the obvious stuff before a human ever looks.

ii

Burp Suite

Manual pen

Pro license per studio member. The right tool when ZAP's automation hits its ceiling.

iii

Snyk

Dependency scan

Open + commercial. Decent CVE feeds, integrates cleanly with GitHub/GitLab.

iv

Semgrep

SAST

Custom rule packs per client. Cheaper than CodeQL, faster to author.

v

Trivy

Container scan

For everyone shipping containers. Catches base-image rot before it reaches production.

06 · Reporting & observability

What we watch at 3 a.m.

Dashboards the team actually opens. Allure for run history; Grafana for live ops; Sentry for the things that escape into production.

i

Allure

Run history

Trend lines + attachment-rich failure detail. The "what broke when" dashboard for the test suite.

ii

ReportPortal

Flake triage

Auto-categorizes test failures across runs. Worth the self-host effort for teams above ~5k tests.

iii

Grafana

Live ops

The single source of dashboards we point oncall at. Loki for logs, Tempo for traces.

iv

Datadog

SaaS observability

Heavy but undeniably good. Synthetic monitoring + RUM in one place.

v

Sentry

Error capture

Frontend + backend exception tracking. Source maps + release tagging mean a one-click bisect to the offending PR.
